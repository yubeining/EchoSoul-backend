# 用户输入到情绪数值的映射机制设计方案

## 概述

本文档详细设计了将用户输入文本转换为情绪数值的完整映射机制。该机制通过多层次分析架构，实现对用户输入的情绪识别、强度分析和数值化转换。

## 1. 整体架构设计

### 1.1 多层次输入解析架构

系统采用分层解析的方式，将复杂的用户输入分解为多个可分析的维度：

```
用户输入 → 文本预处理 → 并行分析模块 → 情绪刺激向量生成
```

**分析模块包括：**
- 情绪分类器：识别基础情绪类型
- 语气词检测器：分析语气强度
- 语义分析器：理解深层意图
- 上下文对齐器：结合历史情绪状态

### 1.2 数据流设计

**输入层：**
- 原始用户文本
- 上下文信息（历史对话、角色设定等）
- 时间戳信息

**处理层：**
- 文本预处理（去噪、分词、标准化）
- 多维度特征提取
- 权重计算和归一化

**输出层：**
- 情绪刺激向量
- 触发线索映射
- 情绪增量计算结果

## 2. 核心组件设计

### 2.1 情绪分类器设计

**功能目标：**
- 识别用户输入中的基础情绪类型
- 提供情绪强度的初步评估
- 支持多种情绪类型的并行识别

**设计要点：**

#### 2.1.1 情绪类型定义
系统支持七种基础情绪类型：
- **快乐**：积极、愉悦的情感状态
- **悲伤**：消极、低落的情感状态  
- **愤怒**：敌对、不满的情感状态
- **恐惧**：害怕、担忧的情感状态
- **惊讶**：意外、震惊的情感状态
- **厌恶**：反感、嫌弃的情感状态
- **平静**：中性、稳定的情感状态

#### 2.1.2 关键词匹配策略
- **精确匹配**：直接关键词识别
- **语义扩展**：同义词和近义词匹配
- **语境权重**：根据上下文调整权重
- **否定处理**：识别否定词对情绪的逆转作用

#### 2.1.3 权重计算机制
- **基础权重**：每种情绪类型的基础权重系数
- **频率权重**：关键词出现频次的权重加成
- **位置权重**：关键词在句子中位置的权重调整
- **组合权重**：多个关键词同时出现的协同效应

### 2.2 语气强度分析器设计

**功能目标：**
- 分析文本中的语气标记和强度指标
- 量化情感表达的强烈程度
- 为情绪数值计算提供强度系数

**设计要点：**

#### 2.2.1 语气标记识别
- **标点符号分析**：
  - 感叹号：表示强烈情感
  - 问号：表示疑问或惊讶
  - 省略号：表示犹豫或思考
  - 重复标点：增强语气强度

- **字符特征分析**：
  - 大写字母：表示强调或愤怒
  - 重复字符：如"哈哈"、"啊啊"等
  - 特殊字符：如表情符号、颜文字等

#### 2.2.2 强度量化算法
- **线性累加**：基础强度值的简单累加
- **指数衰减**：考虑重复标记的递减效应
- **上限控制**：设置最大强度值防止溢出
- **归一化处理**：将强度值标准化到[0,1]区间

#### 2.2.3 语境强度调整
- **句子长度调整**：短句通常情感更强烈
- **词汇密度调整**：情感词汇密度影响整体强度
- **语法结构调整**：倒装、强调句等语法结构的影响

### 2.3 触发线索映射器设计

**功能目标：**
- 将识别的情绪特征映射为具体的情绪增量
- 提供情绪变化的量化指标
- 支持复杂情绪状态的组合计算

**设计要点：**

#### 2.3.1 触发线索分类
- **积极线索**：
  - 感谢类：谢谢、感谢、多亏等
  - 赞美类：厉害、棒、优秀等
  - 安慰类：没事、放心、会好的等

- **消极线索**：
  - 批评类：不好、差、糟糕等
  - 恐惧类：害怕、恐惧、担心等
  - 愤怒类：生气、愤怒、讨厌等

- **中性线索**：
  - 疑问类：什么、怎么、为什么等
  - 陈述类：事实性描述
  - 建议类：应该、可以、建议等

#### 2.3.2 情绪增量计算
- **基础增量**：每种触发线索的基础情绪变化值
- **强度调节**：根据语气强度调整增量大小
- **情绪交互**：不同情绪类型之间的相互影响
- **累积效应**：多个线索的叠加影响

#### 2.3.3 效价和唤醒度计算
- **效价（Valence）**：情绪的正负向程度
  - 正值：积极情绪
  - 负值：消极情绪
  - 范围：[-10, +10]

- **唤醒度（Arousal）**：情绪的激活程度
  - 高值：情绪激动
  - 低值：情绪平静
  - 范围：[0, 10]

### 2.4 上下文对齐器设计

**功能目标：**
- 结合历史对话和角色设定信息
- 提供情绪变化的连续性保障
- 支持个性化的情绪响应模式

**设计要点：**

#### 2.4.1 历史状态整合
- **情绪记忆**：保持最近的情绪状态历史
- **衰减机制**：历史情绪随时间自然衰减
- **阈值判断**：决定是否触发新的情绪变化

#### 2.4.2 角色特征适配
- **性格倾向**：不同角色对相同刺激的不同反应
- **情绪敏感度**：角色对情绪变化的敏感程度
- **表达偏好**：角色偏好的情绪表达方式

#### 2.4.3 场景上下文
- **对话主题**：不同主题对情绪的影响权重
- **关系状态**：用户与角色的关系影响情绪反应
- **环境因素**：虚拟环境对情绪的影响

## 3. 算法实现策略

### 3.1 多维度融合算法

**加权平均法：**
- 为每个分析维度分配权重
- 计算加权平均值作为最终结果
- 支持动态权重调整

**机器学习方法：**
- 使用预训练的情感分析模型
- 支持在线学习和模型更新
- 提供更高的识别准确率

**规则引擎方法：**
- 基于专家知识的规则系统
- 支持灵活的策略调整
- 提供可解释的决策过程

### 3.2 情绪数值标准化

**范围定义：**
- 情绪强度：[0, 10]
- 效价值：[-10, +10]  
- 唤醒度：[0, 10]

**归一化策略：**
- Min-Max标准化
- Z-score标准化
- 软最大值标准化

**边界处理：**
- 截断处理：超出范围的值截断到边界
- 平滑处理：使用平滑函数处理边界值
- 异常检测：识别和处理异常输入

### 3.3 性能优化策略

**计算优化：**
- 并行处理多个分析模块
- 缓存常用计算结果
- 增量更新机制

**存储优化：**
- 压缩历史数据
- 分层存储策略
- 定期清理机制

**实时性保障：**
- 流式处理架构
- 异步计算模式
- 超时控制机制
