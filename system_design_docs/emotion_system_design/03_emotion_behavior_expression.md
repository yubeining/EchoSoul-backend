# 情绪数值到行为表达的映射规则设计方案

## 概述

本文档详细设计了将情绪数值转换为具体行为表达的映射规则系统。通过建立情绪-表达映射表、行为生成器和多模态表达机制，确保AI角色能够根据当前情绪状态展现出相应的语言、动作和音效表达。

## 1. 整体映射架构

### 1.1 映射层次结构

**三层映射架构：**

```
情绪数值 → 表达规则 → 具体行为 → 多模态输出
```

**映射层次说明：**
- **第一层**：情绪数值到表达规则的映射
- **第二层**：表达规则到具体行为的映射  
- **第三层**：具体行为到多模态输出的映射

### 1.2 表达维度定义

**文本表达维度：**
- **语言风格**：正式、随意、亲切等
- **词汇选择**：积极词汇、消极词汇、中性词汇
- **句式结构**：简单句、复合句、疑问句等
- **语气标记**：感叹号、问号、语气词等

**行为表达维度：**
- **面部表情**：微笑、皱眉、惊讶等
- **身体动作**：点头、摇头、手势等
- **姿态变化**：挺直、放松、紧张等
- **动画效果**：跳跃、旋转、闪烁等

**音效表达维度：**
- **语音语调**：音高、音量、语速等
- **背景音乐**：旋律、节奏、音色等
- **音效提示**：提示音、环境音等
- **语音情感**：情感化的语音合成

## 2. 情绪-表达映射系统设计

### 2.1 基础表达规则框架

**通用表达规则：**

#### 2.1.1 句子结构规则
- **偏好结构**：简单句、短句优先
- **避免结构**：复杂从句、长难句
- **长度控制**：根据情绪强度控制句子长度
- **节奏调节**：根据情绪调整句子节奏

#### 2.1.2 语气标记规则
- **密度控制**：语气词密度不超过30%
- **偏好标记**：哦、呀、呢等温和语气词
- **禁止标记**：网络脏话、过度口语化
- **强度调节**：根据情绪强度调整语气标记强度

#### 2.1.3 词汇风格规则
- **正式度等级**：随意、正式、混合
- **技术词汇比例**：不超过10%
- **情感词汇比例**：控制在20%左右
- **个性化词汇**：角色特定的词汇偏好

## 3. 复合情绪表达处理

### 3.1 主次情绪融合机制

**融合策略：**

#### 3.1.1 权重计算
- **主情绪权重**：主情绪强度占总强度的比例
- **次情绪权重**：次情绪强度占总强度的比例
- **动态调整**：根据强度变化动态调整权重

#### 3.1.2 规则混合算法
- **数值型规则**：通过加权平均混合数值型规则
- **布尔型规则**：通过逻辑运算混合布尔型规则
- **列表型规则**：通过合并和去重处理列表型规则

#### 3.1.3 冲突解决机制
- **优先级规则**：定义规则冲突时的优先级
- **折中策略**：在冲突规则间寻找折中方案
- **动态选择**：根据情境动态选择合适规则

### 3.2 情绪强度调节机制

**强度-表达映射：**

#### 3.2.1 强度分级
- **低强度**：[0, 3.0] - 轻微表达
- **中等强度**：[3.0, 7.0] - 明显表达
- **高强度**：[7.0, 10.0] - 强烈表达

#### 3.2.2 表达强度调节
- **感叹号数量**：根据强度调整感叹号数量上限
- **词汇强度**：根据强度选择更强烈的词汇
- **动作幅度**：根据强度调整动作的幅度
- **音效音量**：根据强度调整音效的音量

#### 3.2.3 非线性调节
- **阈值效应**：达到特定阈值时的表达突变
- **饱和效应**：高强度时的表达饱和
- **边际递减**：强度增加对表达影响的递减

**生成策略：**

- **上下文适配**：根据上下文选择合适的动画

#### 4.2.3 动画参数调节
