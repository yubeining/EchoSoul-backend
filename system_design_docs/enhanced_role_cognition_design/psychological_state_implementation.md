# 心理状态维度实现方案

## 概述

心理状态维度负责管理角色的心理健康、情感模式、认知风格和心理发展，确保角色在对话中表现出符合其心理特征的情感反应和思维模式。本方案详细描述了如何构建一个深入、全面的心理状态管理系统。

## 1. 系统架构设计

### 1.1 核心组件结构
```
PsychologicalStateManager
├── MentalHealthManager        # 心理健康管理
├── EmotionalPatternManager    # 情感模式管理
├── CognitiveStyleManager      # 认知风格管理
├── TraumaRecoveryManager      # 创伤恢复管理
├── StressManagementManager    # 压力管理
└── PsychologicalValidator     # 心理状态验证器
```

### 1.2 心理状态层次结构
- **基础心理状态**：基本的心理功能和状态
- **情感心理状态**：情感相关的心理状态
- **认知心理状态**：认知相关的心理状态
- **社会心理状态**：社会交往相关的心理状态
- **发展心理状态**：心理发展和成长状态

## 14. 数据存储结构设计

### 14.1 主数据库表结构 (PostgreSQL)

#### 14.1.1 心理健康表 (mental_health)
```sql
CREATE TABLE mental_health (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    character_id UUID REFERENCES characters(id),
    overall_health_score DECIMAL(3,2) CHECK (overall_health_score >= 0 AND overall_health_score <= 1),
    anxiety_level DECIMAL(3,2) CHECK (anxiety_level >= 0 AND anxiety_level <= 1),
    depression_level DECIMAL(3,2) CHECK (depression_level >= 0 AND depression_level <= 1),
    stress_level DECIMAL(3,2) CHECK (stress_level >= 0 AND stress_level <= 1),
    resilience_level DECIMAL(3,2) CHECK (resilience_level >= 0 AND resilience_level <= 1),
    assessment_date TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### 14.1.2 情感模式表 (emotional_patterns)
```sql
CREATE TABLE emotional_patterns (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    character_id UUID REFERENCES characters(id),
    emotion_type VARCHAR(50) NOT NULL,
    emotion_intensity DECIMAL(3,2) CHECK (emotion_intensity >= 0 AND emotion_intensity <= 1),
    emotion_frequency VARCHAR(50),
    trigger_events JSONB,
    expression_style VARCHAR(50),
    coping_strategies JSONB,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 15. 数据访问接口

### 15.1 RESTful API设计
- **GET /api/characters/{id}/mental-health** - 获取心理健康状态
- **GET /api/characters/{id}/emotional-patterns** - 获取情感模式
- **POST /api/characters/{id}/mental-health** - 创建心理健康记录
- **PUT /api/characters/{id}/mental-health/{health_id}** - 更新心理健康状态

### 15.2 GraphQL接口设计
```graphql

type EmotionalPattern {
```
