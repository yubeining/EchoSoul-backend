# 角色状态数据提取与结构化映射方案

## 概述

本文档详细说明如何从番剧、文本等原始素材中提取角色的六维状态数据，包括价值观与动机、知识边界、情绪/表情状态等，并将其映射为结构化数据供大模型感知使用。

## 一、价值观与动机提取方案

### 1.1 数据源识别
- **主要素材**：
  - 番剧台词对话（带时间戳的完整对话）
  - 轻小说原文段落
  - 角色内心独白
  - 官方设定集和访谈记录
  - 角色行为决策场景

### 1.2 提取方法

#### 1.2.1 主题模型分析
- **工具**：BERTopic、LDA、Sentence-BERT
- **流程**：
  1. 对角色所有台词进行语义向量化
  2. 使用主题模型识别价值相关主题簇
  3. 人工标注主题含义（如：正义、守护、反威权、自尊等）
  4. 计算每个主题在角色话语中的权重分布

#### 1.2.2 行为-理由三元组抽取
- **工具**：语义角色标注（SRL）、知识图谱构建
- **流程**：
  1. 识别角色行为事件（动词短语）
  2. 抽取行为的直接理由和深层动机
  3. 构建 {事件 → 行动 → 理由} 三元组
  4. 聚类相似的理由模式，形成动机标签

#### 1.2.3 专家标注体系
- **价值观标签定义**：
  - 利他主义：关注他人福祉的程度
  - 自尊维护：保护自身尊严和地位的倾向
  - 责任感：承担义务和责任的强度
  - 反威权：反抗权威和压迫的态度
  - 正义感：追求公平和正义的倾向
  - 忠诚度：对特定人或组织的忠诚程度

- **标注流程**：
  1. 制定详细的标注指南和示例
  2. 多人标注同一批数据，计算一致性
  3. 冲突条目进入专家评审
  4. 建立标注质量评估指标（Kappa系数 > 0.75）

### 1.3 结构化输出

```json
  "value_profile": {
    "justice_oriented": 0.85,
    "altruism": 0.78,

    "responsibility": 0.88
  },
  "motivation_patterns": [
    {
      "trigger": "weak_person_being_bullied",
      "action": "intervene_and_protect",
      "reason": "cannot_ignore_injustice"
    }
  ]
}
```

## 二、知识边界提取方案

### 2.1 知识分类体系

#### 2.1.1 角色知识基线构建
- **官方设定知识**：
  - 角色背景信息（年龄、身份、能力等）
  - 世界观设定（学园都市、能力等级等）
  - 人际关系网络
  - 时间线事件记录

- **角色专属知识**：
  - 个人经历和记忆
  - 专业技能和学科知识
  - 社交圈内信息
  - 个人秘密和隐私

#### 2.1.2 知识边界类型
- **绝对未知**：角色从未接触过的信息
- **部分了解**：知道存在但不了解细节
- **误解信息**：角色认知错误的信息
- **主动回避**：知道但不愿讨论的话题
- **禁忌知识**：角色不应知晓的敏感信息

### 2.2 提取方法

#### 2.2.1 对话知识检测
- **工具**：BERT-based QA模型、知识图谱匹配
- **流程**：
  1. 构建角色知识基线知识库
  2. 从台词中提取涉及的信息点
  3. 与知识库对比，标记知识状态
  4. 识别角色主动回避或拒绝讨论的话题

#### 2.2.2 时间线知识验证
- **方法**：事件时间戳对比
- **流程**：
  1. 建立世界观事件时间线
  2. 标记每个事件的知晓范围
  3. 验证角色在特定时间点的知识状态
  4. 识别未来信息的"预言"错误

#### 2.2.3 专家验证与标注
- **标注指南**：
  - 明确每个知识点的知晓程度（0-1评分）
  - 标注信息来源和可信度
  - 识别知识边界的变化时机
  - 标记特殊的知识获取限制

## 三、情绪/表情状态提取方案

### 3.1 多模态情绪识别

#### 3.1.1 视觉情绪分析
- **工具**：Facial Action Coding System (FACS)、OpenFace、FER2013
- **流程**：
  1. 从番剧帧中检测人脸区域
  2. 提取面部动作单元（AU）
  3. 映射到基础情绪类别（愤怒、快乐、悲伤、惊讶、恐惧、厌恶）
  4. 计算情绪强度（0-1连续值）

#### 3.1.2 语音情绪分析
- **工具**：Librosa、OpenSMILE、Wav2Vec2
- **特征提取**：
  - 声学特征：基频(F0)、能量、语速、频谱特征
  - 韵律特征：停顿模式、语调变化
  - 深度特征：预训练语音模型的隐藏状态

#### 3.1.3 文本情绪分析
- **工具**：RoBERTa、BERT情感分类器、VADER
- **流程**：
  1. 对台词文本进行情感分类
  2. 识别情绪相关的词汇和表达
  3. 分析语气词和标点符号的情感暗示
  4. 考虑上下文对情绪的影响

### 3.2 多模态融合策略

#### 3.2.1 特征级融合
- **方法**：早期融合、中期融合、晚期融合
- **权重分配**：
  - 视觉：30%（面部表情）
  - 语音：40%（声音特征）
  - 文本：30%（语义内容）

#### 3.2.2 注意力机制
- **实现**：Transformer注意力层
- **功能**：
  1. 动态调整不同模态的权重
  2. 处理模态缺失情况
  3. 捕获跨模态的情绪一致性

### 3.3 情绪状态建模

#### 3.3.1 离散情绪分类
- **基础情绪**：Ekman六种基础情绪
- **复合情绪**：害羞、骄傲、嫉妒、愧疚等
- **角色专属情绪**：基于角色特点定义的特殊情绪状态

#### 3.3.2 连续情绪空间
- **维度模型**：Valence-Arousal-Dominance (VAD)
- **应用**：
  - Valence：积极/消极程度
  - Arousal：激活/平静程度
  - Dominance：控制/被控制程度

#### 3.3.3 情绪时间序列
- **建模方法**：LSTM、GRU、Transformer
- **功能**：
  1. 捕获情绪的动态变化
  2. 预测情绪状态转换
  3. 识别情绪触发事件

## 四、数据质量控制与验证

### 4.1 一致性检查
- **跨模态一致性**：视觉、语音、文本情绪标签的一致性
- **时间一致性**：情绪变化的合理性和连续性
- **角色一致性**：情绪反应符合角色性格设定

### 4.2 标注质量控制
- **多人标注**：至少3人标注同一数据
- **一致性指标**：Kappa系数 > 0.75
- **专家评审**：冲突案例进入专家判定流程

### 4.3 数据版本管理
- **变更日志**：记录每次数据更新的内容
- **质量报告**：生成数据质量评估报告
- **回滚机制**：支持数据版本回退

## 五、实施建议

### 5.1 技术栈推荐
- **ASR**：Whisper-large、NeMo-ASR
- **多模态分析**：OpenMMLab、Hugging Face Transformers
- **向量数据库**：Milvus、Qdrant
- **标注平台**：Label Studio、Prodigy

### 5.2 实施优先级
1. **第一阶段**：建立基础数据schema和标注指南
2. **第二阶段**：完成单角色试点验证（御坂美琴）
3. **第三阶段**：扩展到多角色，建立自动化pipeline
4. **第四阶段**：集成到大模型感知系统

### 5.3 质量评估指标
- **提取准确性**：与专家标注的F1分数 > 0.85
- **一致性指标**：标注者间一致性 > 0.75
- **实用性指标**：大模型响应符合度 > 0.80

## 六、注意事项

### 6.1 版权与法律
- 确保素材来源的合法性
- 遵守相关版权法规
- 建立数据使用授权机制

### 6.2 伦理考虑
- 尊重角色原设定的完整性
- 避免过度解读或歪曲角色特征
- 建立内容审核机制

### 6.3 技术限制
- 自动提取的局限性
- 需要人工校验和修正
- 持续迭代和改进的必要性
